### [What is OAuth?](#-)

link [OAuth vs JWT](https://supertokens.com/blog/oauth-vs-jwt)

OAuth (Open Authorization) - often written as the latest version OAuth 2.0 - is a protocol that is used to authenticate a user via an authentication server. <?br>
One of the useful things about OAuth is that it enables you to delegate account access in a secure way without sharing credentials. </br>
Instead of credentials, OAuth relies on access tokens. </br>
Using access tokens, a client application can verify the identity of the user that authenticated themselves.

When you implement “Sign in with Google” or “Sign in with Github”, you are using the OAuth 2.0 protocol!  </br>
